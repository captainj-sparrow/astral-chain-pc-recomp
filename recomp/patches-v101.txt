# Dynamic frame rate for the 60 fps mode (the menu's AC_FPS: 30 = shipping 30 fps, 60 = 60 fps with the fix).
# This replaces the community static 60 fps patch (MrComputerRevo's IPS, whose offsets count the 0x100-byte NSO header)
# with the Dynamic mod v1.1.1's fixes for its two 60 fps bugs: the frame accumulator's low clamp drops to 1/16 (the
# high clamp stays the original 2.0) so the floating step tracks real time; every input/action frame counter is scaled
# by the whole-tick count (runtime/frame_rate.c) so its window lasts wall-clock time instead of whole 60 fps frames;
# and the camera's per-frame smoothing blend becomes 1 - powf(1 - a, clamp(step, 0, 4)) so it converges at the same
# rate whatever the frame rate. The frame call's second-vsync wait is still cleared; the present pacer (nvn_api_obj.c)
# holds 60 fps. AC_FPS=30 runs the original instructions (the game's shipping 30 fps).
